# Sistema de Reserva de Clases - Gimnasio

Proyecto desarrollado para el curso de Programación de Lenguajes de Cuarta Generación. 
Esta es la **Entrega 1 (Avance I)**, que incluye los módulos de Registro/Login, Gestión de Clientes y Gestión de Clases.

## Tecnologías utilizadas
* Java 27
* Spring Boot 3.x
* Spring Security
* Spring Data JPA / Hibernate
* Base de datos H2 (en memoria)
* Thymeleaf + Bootstrap 5
* Maven

## Cómo ejecutar el proyecto
1. Clona este repositorio o descarga el código fuente.
2. Abre una terminal en la raíz del proyecto (donde está el archivo `pom.xml`).
3. Ejecuta el siguiente comando:
```bash
mvn spring-boot:run
